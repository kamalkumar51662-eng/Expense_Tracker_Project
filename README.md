# Expense Tracker

## Project Overview
Expense Tracker is a Python console app that helps you keep track of your daily spending. It’s simple to use and runs in the terminal.
You can add expenses by typing in the date category, a note about what it was for and the amount. Later you can look at all your saved expenses. See how much you’ve spent in total.
While the program is running it stores each expense in a list of dictionaries. That way it can remember everything until you close the app.

## Features
- Add an expense
- Type in the date of the expense
- Choose or type the expense category
- Add a description, for the expense
- Enter the amount spent
- See all saved expenses
- Find the total amount spent
- Easy-to-use menu system
- Quit the app when done
