# Expense Tracker Project

## 1. Problem Statement

Managing daily expenses manually can be difficult and time-consuming. It may be hard to keep track of individual expenses and calculate the total amount spent.

The **Expense Tracker** is a Python-based console application that allows users to record, view, and calculate their expenses in an organized way.

## 2. Scope of the Project

The scope of this project includes:

- Adding new expenses with date, category, description, and amount.
- Storing multiple expenses during program execution.
- Viewing all recorded expenses.
- Calculating and displaying the total expenditure.
- Providing a simple menu-driven interface.
- Allowing the user to exit the application whenever required.

This project is designed for basic personal expense management and learning Python programming concepts such as lists, dictionaries, loops, conditional statements, user input, and arithmetic operations.

## 3. Target Users

The target users of this project are:

- Students who want to track their daily expenses.
- Individuals who want a simple way to record spending.
- Beginners learning Python programming.
- Users who need a basic console-based expense management system.

## 4. High-Level Features

### 1. Add Expense
The user can enter:
- Date of the expense
- Category of the expense
- Description of the expense
- Amount spent

### 2. View Expenses
The program displays all the expenses entered by the user along with their details.

### 3. View Total Expense
The program calculates and displays the total amount of all recorded expenses.

### 4. Exit
The user can exit the Expense Tracker program using the Exit option.

### 5. Menu-Driven Interface
The program provides a simple menu with four options:

1. Add Expense
2. View Expense
3. View Total Expense
4. Exit
